# ترحيل Sanity إلى Convex

الأداة مخصّصة لمخطط هذا المشروع: `books` و`biography` و`lessonsPage`. تستخدم Node 24 وConvex المثبّت في المشروع. لا تقرأ مفاتيح تسجيل الدخول أو تطبعها، ولا تحتاج إلى تثبيت حزم جديدة. تستعمل تسجيل دخول Convex CLI الحالي. ملفات `.env.sanity` و`.env.local` و`.env.migration` تُقرأ محليًا؛ متغيرات العملية لها الأولوية.

## الخطوات

من جذر المشروع:

```powershell
npm run migrate:backup
```

يحفظ التصدير في مجلد جديد داخل `.migration-runs`: مستندات Sanity الخام، الصور والملفات، `convex.zip` شاملاً Storage، حالة الجداول المستهدفة، وبصمات SHA-256. لا يُكتب شيء في جداول المحتوى. طلب تصدير Convex ينشئ لقطة احتياطية على الخدمة قبل تنزيلها.

عند غياب `SANITY_READ_TOKEN` أو `SANITY_API_TOKEN` يقتصر تصدير Sanity على البيانات المتاحة للعامة. لا يدّعي نسخ المسودات أو البيانات الخاصة. صور CDN العامة قد تختلف عن الملف الأصلي في الضغط والبيانات الوصفية؛ تُحفظ البايتات المستلمة وتُفحص بصمتها، ويذكر التقرير هذا الفرق. عند توفر رمز قراءة يستعمل `dlRaw` ويشترط تطابق SHA-1 والحجم مع الأصل. لا ترسل رموز Sanity إلى وجهة غير عنوان Sanity الموثق للمشروع، ولا تتبع التحويلات.

```powershell
npm run migrate:sanity -- --run .migration-runs/RUN_DIRECTORY
```

هذا **dry-run افتراضي**. يفشل عند نقص البيانات المطلوبة أو وجود محتوى مسبق في الجداول؛ لا يمسحه ولا يدمجه ضمنيًا. ينتج `plan.json` و`report.md` و`page-texts-review.json`. لا يعدّل ملفات اللغات الثابتة تلقائيًا. الاحتفاظ بعناوين الصفحات خارج قاعدة البيانات يتوافق مع المخطط الحالي.

خيارات المراجعة:

- `--translations PATH`: ملف ترجمة جديدة. المفاتيح `SOURCE_ID.title` أو `biography.description.blocks.INDEX`، وقيمة كل مفتاح `{ "sourceText": "النص العربي المطابق", "en": "...", "tr": "..." }`. تغيّر العربية يبطل الترجمة. عند استعمال هذا الملف لا تُستخدم الترجمات القديمة كبديل.
- `--corrections PATH`: تصحيحات تحريرية موثقة بالنص القديم والجديد والسبب، مرتبطة بمستند وكتلة محددين. تُحفظ داخل الخطة. لا يغيّر الملف المصدر الاحتياطي.
- `--allow-missing-text`: تمثيل الحقول النصية والتواريخ غير الموجودة بسلسلة فارغة مع تحذير. لا يولّد وصفًا أو ترجمة أو تاريخًا أو ترتيبًا؛ نقص `order` أو الرابط التعريفي أو المراجع يوقف الاستيراد.
- `--replace-test-data`: يسمح بخطة استبدال الجداول الثلاثة، **محصور ببيئة التطوير التي وافق عليها المستخدم `cheerful-horse-763`**. الوضع الافتراضي لا يمسح شيئًا.

بعد مراجعة الخطة والموافقة عليها، تُنشر وظائف `convex/sanityMigration.ts` الداخلية إلى بيئة التطوير باستخدام `npx convex dev --once --typecheck enable`، ثم:

```powershell
npm run migrate:sanity -- --run .migration-runs/RUN_DIRECTORY --apply --approve EXACT_PLAN_SHA256
```

الأداة لا تنشر كودًا ضمنيًا ولا تستورد دون البصمة المطابقة. تغيير الخطة أو البيئة يبطل الموافقة. لا تستعمل `--prod`. فحص تغير الجداول يتم مجددًا داخل معاملة الاستيراد، فلا يُستبدل تعديل حدث منذ dry-run. الصور تُرفع أولًا وتُفحص، ثم تؤخذ نسخة Convex إضافية، ثم تُستبدل بيانات الجداول وتُحوّل مراجع الكتب داخل **معاملة واحدة**. فشل المعاملة لا يترك جداول مستوردة جزئيًا.

يُحفظ `uploads.json` لاستكمال الرفع، و`receipt.json` لربط Sanity IDs بـConvex IDs. إعادة الأمر بنفس الخطة تتعرف على التنفيذ المكتمل ولا تكرر الكتب. عند فشل عملية الرفع بعد وصول الملف وقبل حفظ سجلّه قد يبقى ملف غير مرتبط؛ الأداة لا تحذف ملفات Storage تلقائيًا، لأنها قد تكون مشتركة مع صفحات أخرى. إذا توقف التشغيل بالقوة وبقي `apply.lock`، تأكد أولًا من عدم وجود عملية استيراد تعمل ثم احذف ملف القفل وحده لإعادة المحاولة.

بعد التنفيذ، تُقارن جميع حقول الجداول الثلاثة بالخطة حرفيًا وتُفحص بصمات الصور، وتُحفظ النتائج في `verification.json` و`after.json`. لا يُعد وجود `receipt.json` وحده دليلًا على اكتمال الفحص.

## المحتوى والتحقق

- المنشور فقط يُنقل؛ لا تُنشر المسودات أو نسخ الإصدارات.
- Portable Text يُحوّل إلى Markdown نصي مع الفقرات والعناوين والقوائم والروابط والتأكيدات المدعومة. الكتل والتعليقات غير المفهومة توقف الاستيراد بدل إسقاط المحتوى. الأصل الكامل محفوظ دائمًا.
- قصّ الصور ونقطة التركيز محفوظان في التصدير الخام، لكن مخطط Convex يحتفظ بمعرّف الصورة فقط؛ تُرفع الصورة كاملة ويصدر تحذير إن وُجد قص أو نقطة تركيز.
- نوع Sanity القديم `book` خارج مخطط `books` محفوظ في النسخة ولا يُضاف تلقائيًا ككتاب مكرر.
- الحد المقصود لهذه الأداة 200 كتاب وحزمة صغيرة تناسب معاملة واحدة؛ ما يتجاوز الحدود يوقف الخطة ويحتاج تصميمًا آخر.
- ملفات النسخ والخطط والترجمات والمفاتيح مستثناة من Git. لا توجد عملية استرجاع مدمرة تلقائية؛ احتفظ بالـZIP والنسخ الخام قبل أي استرجاع يدوي.

```powershell
npm run test:migration
npx tsc --noEmit --incremental false
```

اختبارات الأمان تشمل تغيّر الوجهة، منع الكتابة الافتراضي، سلامة المراجع، الصور المفقودة، تكرار الروابط التعريفية، إعادة المحاولة، الكتل غير المدعومة، والترجمات القديمة.
